# Claude-KillSwitch

Claude Code VPN Kill Switch (Windows 11) — это легкий фоновый PowerShell-скрипт для защиты аккаунта Anthropic при работе через терминал. Он контролирует активность VPN-клиента (например, Happ) и проверяет реальную страну вашего внешнего IP-адреса. Если соединение обрывается, клиент закрывается или IP не совпадает с разрешенным регионом, скрипт мгновенно принудительно завершает процессы claude и отправляет системное уведомление на рабочий стол.
